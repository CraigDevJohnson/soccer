# Code of conduct

Everyone who takes part in this project, in issues, pull requests or reviews, keeps it a harassment-free experience for everyone.

- Be respectful and constructive.
- Focus on the technical merits.
- Assume good faith.

Report abusive behavior to privacy@craigdevjohnson.com.

*Adapted from the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).*
